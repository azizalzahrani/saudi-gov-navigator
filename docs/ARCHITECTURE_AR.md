# العمارة والهندسة المعمارية

## دليل الخدمات الحكومية السعودية - البنية المعمارية

### نظرة عامة

يوفر هذا المشروع بنية معمارية متقدمة لتوجيه المستخدمين خلال الخدمات الحكومية السعودية. يتم تنظيم النظام في طبقات منفصلة لتحقيق الفصل بين الاهتمامات والقابلية للصيانة.

## الطبقات المعمارية

### 1. طبقة قاعدة المعرفة (Knowledge Base Layer)
**الموقع**: `saudi_gov/knowledge_base/`

تحتوي على جميع بيانات الخدمات الحكومية في ملفات JSON:
- `absher.json` - خدمات أبشر
- `muqeem.json` - خدمات معايش
- `qiwa.json` - خدمات قوى العمل
- `tawakkalna.json` - خدمات تواصل
- `balady.json` - خدمات بلدي
- `misa.json` - خدمات الهيئة العامة للاستثمار
- `hrsd.json` - خدمات التأمينات الاجتماعية
- `nitaqat.json` - خدمات نطاقات

**المسؤوليات**:
- تحميل البيانات من ملفات JSON
- البحث عن الخدمات حسب المعرفات
- استرجاع خدمات المنصة المحددة

### 2. طبقة البحث (Search Layer)
**الموقع**: `saudi_gov/search.py`

توفر إمكانيات البحث الدلالي:
- البحث بالكلمات الرئيسية
- الإكمال التلقائي
- التصفية حسب الفئة والمنصة والرسوم
- البحث المتقدم مع عدة مرشحات
- إيجاد الخدمات المرتبطة

**الميزات**:
- فهرسة شاملة لجميع الخدمات
- حساب درجات الصلة (Relevance Scoring)
- دعم البحث بالعربية والإنجليزية

### 3. طبقة الوكلاء (Agents Layer)
**الموقع**: `saudi_gov/agents/`

تحتوي على ثلاث وكلاء رئيسية:

#### أ. وكيل الملاح (NavigatorAgent)
المسؤول عن:
- معالجة استفسارات المستخدم
- تنسيق الاستجابات
- توفير التوجيهات الشاملة
- مقارنة الخدمات
- تنسيق الاستجابات

#### ب. وكيل البحث (ServiceFinder)
المسؤول عن:
- البحث عن الخدمات حسب الاستعلامات
- الوصول إلى معلومات المنصات
- تصنيف الخدمات
- اقتراح الخدمات بناءً على السيناريوهات

#### ج. وكيل المتطلبات (RequirementsAgent)
المسؤول عن:
- استخراج متطلبات الخدمات
- توفير خطوات المعالجة
- الحصول على معلومات الرسوم
- توفير النصائح والتحذيرات الشائعة

### 4. طبقة المساعدات (Utilities Layer)
**الموقع**: `saudi_gov/utils/`

#### أ. مساعدات النصوص العربية (arabic_utils.py)
- تطبيع النصوص العربية
- إزالة التشكيل
- التحقق من وجود نصوص عربية
- التحويل الصوتي (Transliteration)
- التحقق من صحة الهوية والإقامة ورقم الهاتف

#### ب. حاسبة الرسوم (fee_calculator.py)
- تنسيق المبالغ بالريال السعودي
- تحويل العملات
- حساب الرسوم الإجمالية
- تطبيق الخصومات
- مقارنة تكاليف الخدمات

### 5. طبقة واجهة المستخدم (UI Layer)
**الموقع**: `saudi_gov/chatbot.py`

دردشة آلية تفاعلية توفر:
- واجهة سطر أوامر ودية
- معالجة الأوامر والاستعلامات
- عرض النتائج بتنسيق منظم
- دعم اللغة العربية والإنجليزية

### 6. طبقة الإعدادات (Configuration Layer)
**الموقع**: `saudi_gov/config.py`

إدارة الإعدادات:
- متغيرات البيئة
- اختيار مزود LLM (OpenAI/Anthropic)
- إعدادات اللغة
- نقاط نهاية الخدمات

## تدفق البيانات

```
المستخدم
   ↓
[واجهة الدردشة]
   ↓
[وكيل الملاح]
   ↓
├─→ [وكيل البحث] ──→ [محرك البحث]
├─→ [وكيل المتطلبات] ──→ [قاعدة المعرفة]
└─→ [مساعدات]
   ↓
[النتيجة المنسقة]
   ↓
المستخدم
```

## تفاعل المكونات

### سيناريو البحث عن خدمة

1. المستخدم يكتب استعلاماً في الدردشة
2. وكيل الملاح يستقبل الاستعلام
3. وكيل البحث يستخدم محرك البحث للبحث عن الخدمات
4. محرك البحث يفهرس قاعدة المعرفة ويرجع النتائج
5. يتم ترتيب النتائج حسب الصلة
6. يتم تنسيق الاستجابة وعرضها للمستخدم

### سيناريو الحصول على المتطلبات

1. المستخدم يختار خدمة محددة
2. وكيل المتطلبات يسترجع معلومات الخدمة من قاعدة المعرفة
3. يتم استخراج المتطلبات والخطوات والرسوم
4. يتم تنسيق البيانات للعرض
5. يتم إرسال النتائج للمستخدم

## التوسعية

### إضافة خدمات جديدة

1. إنشاء ملف JSON جديد أو تحديث الملف الموجود
2. اتباع معيار البيانات المحدد
3. التأكد من المحتوى الثنائي اللغة
4. إعادة تحميل قاعدة المعرفة

### إضافة منصات جديدة

1. إنشاء ملف JSON جديد في `knowledge_base/`
2. إضافة معرف المنصة إلى `PLATFORMS` في `config.py`
3. تحديث القائمة `platforms` في `knowledge_base/__init__.py`

## الأداء والتحسينات

### الفهرسة
- جميع الخدمات مفهرسة عند البدء
- يسمح بـ بحث سريع

### تخزين مؤقت (Caching)
- يمكن إضافة طبقة تخزين مؤقت للاستعلامات المتكررة
- تحسين الأداء للمستخدمين المتكررين

### التوازي (Parallelization)
- يمكن تحميل الخدمات بشكل متوازي
- تحسين وقت البدء

## الأمان والخصوصية

- لا تخزين بيانات المستخدم
- لا تسجيل المعلومات الشخصية
- البيانات عبارة عن معلومات عامة من الحكومة السعودية
- دعم HTTPS للاتصالات الآمنة

## المستقبل والتحسينات

- دعم LLM متقدم (OpenAI/Anthropic)
- تعلم الآلة لتحسين البحث
- التكامل مع واجهات برمجية حقيقية للخدمات الحكومية
- دعم الأسئلة متعددة الخطوات
- تحليل المشاعر
- توصيات مخصصة بناءً على الملف الشخصي
